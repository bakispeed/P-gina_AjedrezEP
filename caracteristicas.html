Características del juego

  1. Mecanicas del Juego

    2. • Movimientos básicos de todas las piezas.
    • Captura de piezas enemigas.
    • Alternancia de turnos.
    • Enroque (corto y largo).
    • Avance doble inicial de peones.
    • Detección del fin de partida (captura del rey)

  2. Elementos en la interface.

    3. • Peonegro / Peonblanco.
    • Caballonegro / Caballoblanco.
    • Torrenegra / Torreblanca.
    • Alfilnegro / Alfilblanco.
    • Reynegro / Reyblanco.
    • Reinanegra / Reinablanca.
    • Tableroajedrez / tablero-ajedrez(un tablero funciona como el fondo y el otro permite que se puedan poner las piezas encima).

  3. Fortalezas del Diseño.

    4. • Modularidad: El uso de herencia permite reutilizar código común.
    • Encapsulamiento: Cada pieza conoce sus propios movimientos válidos.
    • Extensibilidad: Es relativamente sencillo añadir nuevas reglas o características.
    • Visualización: Los movimientos posibles se muestran claramente.

  4. Paquetes necesarios

    5. • Visual Studio Code.
    • Python Ultima versión.
    • PIP(gestor de paquetes).
    • PYGAME(librería).
